# Default Teaching Content Prompt

Use this only after the official scope packet and coverage plan are complete.

## Goal

Create a complete teaching document for the **requested bounded unit/chapter only**. Assume the learner is encountering the material systematically for the first time.

The document should move through this learning arc where appropriate:

**Curiosity → Question → Need for a model → Concept → Representation → Equation/relationship → Reasoning → Application → Return to the original question**

## Source authority

The supplied scope packet is authoritative for what is required, excluded, and bounded. Enrichment may deepen explanations but may not silently expand official requirements. Clearly label optional extensions.

## Teaching design

Use a strong unit-level driving question when it genuinely supports the content. For major concepts, use short micro-hooks only when they reveal a misconception, counterintuitive result, or useful need for a new concept.

For important concepts, aim for this structure when it helps learning:

1. Hook/question
2. Intuition
3. Formal definition
4. Why the concept is needed
5. Physical/disciplinary meaning
6. Representation(s)
7. Equation/relationship when applicable
8. Why it works
9. Conditions/boundaries
10. How to recognize it in a problem
11. Application/worked example
12. Common misconception check

Do not mechanically repeat all twelve headings for every small idea.

## Representations and problem solving

Connect verbal descriptions, diagrams, graphs, equations, tables, and other course-relevant representations rather than teaching them as isolated facts.

Explicitly teach recognition: what cues in a problem should make the learner think of a given concept/model?

Use worked examples that expose the first thought, model choice, reasoning, solution, and common wrong path.

## Assessment alignment

Integrate the practices/skills/assessment objectives in the scope packet. Respect all boundary statements. Do not present extension material as required exam content.

## Ending

Finish with:

- return to the driving question when one was used;
- a knowledge map showing conceptual dependencies;
- formula/relationship summary with meaning and conditions when applicable;
- problem-type recognition map;
- major misconceptions;
- an `I can...` checklist mapped to the official requirements.

## Style

Use the user's requested language. Keep official terminology precise. Explain before compressing into formulas. Prefer clear, natural teaching prose over encyclopedia-style listing.
